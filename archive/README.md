# Archive

Files removed from the coven projects to keep them lean: superseded versions of documents, and finished research scripts with their result tables. Nothing here is used by any project or weekly task. Saved Oct 19, 2026, from zips the projects exported that day.

Layout: `archive/<project>/<path as it was in the project>`.

**Kicker caveat:** the Kicker files were retyped by the Kicker project chat when it built its zip, not copied byte for byte. The production scripts were proved by running them (see `CHECKS.md`); the archived research scripts were not rerun. Their logs stayed in the Kicker project and are the record of what each test found.
